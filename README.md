# WandelGame

## Description
WandelGame is a Python terminal-based adventure game developed during the MolenGeek coding school. The game features a simple yet engaging exploration and combat system where players control a Hero character to navigate through various challenges, fight enemies, and manage an inventory.

## Features
- Hero and Enemy classes with distinct attributes and behaviors
- Turn-based combat system
- Inventory management for items and equipment
- Exploration of different areas with random encounters
- Simple text-based interface for immersive gameplay

## Installation
To get started with WandelGame, clone the repository and ensure you have Python 3 installed on your system.

```bash
git clone https://github.com/Sleima/WandelGame.git
cd WandelGame
```

## Usage
Run the main game script from the terminal:

```bash
python main.py
```

Follow the on-screen prompts to play the game. Use the keyboard to navigate and make choices during exploration and combat.

## Tests
To run the test suite and verify the game components are working correctly, use:

```bash
python -m pytest tests -q
```

Ensure you have all dependencies installed before running tests.

## Technologies
- Python 3
- Standard Python libraries for terminal input/output and testing
